## MVP分類

- 必須: 被保険者、認定者、保険料収入、介護保険給付、サービス別給付。
- 可能なら: 計画対実績、事業所・施設・定員、職員数、東京都参考賃金。
- MVP外: 定義の揃わない系列の結合、推計による市値、全国・自治体比較、将来予測。

## 調査上の注意

- 現在の事業所一覧PDFは単時点であり、その件数を過去と比較してはならない。
- 介護サービス施設・事業所調査は施設・事業所数、従事者数、利用者数を公表するが、立川市粒度で継続的に同一定義の値を取得できるかは未確認。
- 東京都毎月勤労統計は東京都参考値としてのみ扱い、立川市の介護職賃金とは表現しない。
- 計画値は予測ではなく自治体が当時設定した値として、実績と年度・指標定義が一致する場合に限り比較する。
