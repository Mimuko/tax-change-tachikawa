# 立川市×子育て ストーリー設計（PoC）

## Act 構成

1. **Opening（Scrolly）** — 妊娠届出者数・保育園児数（年度累計 vs 4月1日時点をコピーで明示）
2. **Interlude** — 乳幼児の数から「受け皿と学童へ」
3. **Act 2** — 保育定員・職員数（2016–、4月1日）＋ 学童登録児童数（年度）
4. **DataGap** — 待機児童の年次推移
5. **Act 3** — 子ども家庭支援センター相談件数（年度末・年間累計）
6. **支援への接続** — 相談件数と `not_measurable`（接続率）
7. **Recap / Detail** — 児童手当は DataGap（制度改定）

## 表現上の注意

- 妊娠届出・手帳交付を出生数の代理としない。
- 保育園児数は「原因別」の合計行（年齢=全て）のみ使用。
- 相談件数は延べ件数であり、支援が必要な家庭すべてに届いたことを示さない。
