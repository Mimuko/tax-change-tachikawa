# MY-239 追加テーマ選定・立川市 PoC

調査日: 2026-09-27。既存の介護・教育と同じく、公開一次資料の年次系列を根拠とし、変化と関係性を示す。候補の実データ確認範囲は立川市の公開表とし、他自治体への横展開は**同種の表がある場合の設計上の可能性**であって可用性の確認済み判定ではない。

## 採用理由と実装範囲

立川市を選んだのは、同じ[市の一次ページ](https://www.city.tachikawa.lg.jp/shisei/tokei/1007009/1007020.html)から、保育園全園の定員・実施児童・職員と、子ども家庭支援センターの相談件数を取得できるため。市のページは CSV ごとに CC BY 4.0 を明示している。原本の CP932 CSV を `data/raw/tachikawa/childcare/` に同梱し、`scripts/build-childcare.mjs` が5年分を検証して processed JSON に変換する。原本 SHA-256、ファイル URL、指標定義を指標別に保持する。

| 指標 | 原表の場所・期間 | 地域 | 使い方・限界 |
|---|---|---|---|
| 定員総数・実施児童数・職員数 | [保育園別定員等 CSV](https://www.city.tachikawa.lg.jp/_res/projects/default_project/_page_/001/007/020/6-2-3hoikuenbetsuteiin_hoikunojisshijidosutoshokuinsu8.csv) の「全園」行、2019–2023年 | 立川市 | 同じ原表・同じ年次値として比較。原表が基準日を明示していないため、4月1日・年度末等とは呼ばない。職員は常勤換算ではない |
| 子育て相談件数 | [子ども家庭支援センター利用状況 CSV](https://www.city.tachikawa.lg.jp/_res/projects/default_project/_page_/001/007/020/6-2-5kodomokateishiensenta-riyojokyo8.csv)、2019–2023年度 | 立川市 | 年度内の延べ件数。相談者数・困りごとの発生件数ではない。年次値と同一グラフに混ぜない |

2019→2023年の定員は3,794→3,853人、実施児童は3,798→3,617人、職員は782→705人。相談は2019→2023年度で11,773→17,302件。これらは**同じ時期に観測された変化**であり、相互の因果関係や政策成果を示さない。

定員と実施児童数の差から待機児童数を推計しない。待機児童の系列は今回の原表には無いため `DataGap` として扱う。相談件数を保育ニーズ全体の代理にもしない。公費支出の連続系列と、子どもの生活上の outcome は今回の PoC に含めない。

## 既存機能の継承

`StoryExperience` の累積表示、`StoryAct`、`StoryInterlude`、`StoryRecap`、`DetailAccordion`、`GeographyChip`、共通グラフ、共有リンク、出典ページ、レスポンシブと reduced motion の共通挙動を再利用する。イベントレイヤーは共通 resolver を通すが、根拠を確認したテーマ固有イベントがないため登録せず、レイヤーを表示しない。都道府県参考値を利用しないため `referenceOnly` / 都道府県 chip は不要。待機児童は数値を補わず DataGap とする。

PoC 再生成: `node scripts/build-childcare.mjs`。原本の更新時は同じ URL から CSV を再取得し、ヘッダー・対象年・SHA と表示値を再監査する。標準の `npm run data:build` と `npm run build` にも生成を組み込む。
