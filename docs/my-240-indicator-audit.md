# MY-240 既存ストーリーの不足指標監査

調査日: 2026-09-27

## 対象と説明が途切れる箇所

公開単位は立川市×介護、練馬区×介護、立川市×教育。介護は需要・給付・提供単位数・都参考の人員／賃金・保険料基準額を示し、立川市では非利用者の障壁と相談相手がいない割合を「支援への接続」で示している。しかし相談・専門支援へ実際につながった側の観測値がなく、Input / Output から Reach への関係が片側だけだった。練馬区は同等の調査原典を未確認であり、立川市の値を流用しない。教育は相談件数を Output として示し、必要な人に対する到達率を測れないことを DataGap として表示している。

## 候補と採否

| 候補 | 判断 | 理由 |
|---|---|---|
| 主な介護者がケアマネジャーに相談している割合（立川市） | **採用** | 市の在宅介護実態調査・問41に2022年の対象、設問、回答母数、値がある。既存の「支援への接続」に相談の実際の接点を加えられる。単時点の回答割合として表示する。 |
| 主な介護者の介護離職割合 | 見送り | 同じ調査に回答はあるが、介護者個人の離職率でも労働統計の離職率でもない。既存ストーリーへそのまま並べると誤解を生む。 |
| 施設・通所の定員 | 見送り | 公表ODの定員欄に0と空欄が混在し、欠測と実定員0を区別できない（`docs/metrics.md`）。 |
| 練馬区の支援への接続 | 見送り | 同等原典の定義と対象者を未確認。立川市の値は移植しない。 |
| 教科別授業時数・学力指標（教育） | 対象外 | [MY-237](https://linear.app/myworkspace1126/issue/MY-237/) で対応。 |
| 自治体間の直接比較 UI | 対象外 | [MY-166](https://linear.app/myworkspace1126/issue/MY-166/) で対応予定。 |

## 採用指標の監査

- 正本: `config/topics/care.json` の `caregiver_care_manager_consultation_pct`。値と出典は `config/data-sources/tachikawa/care.json`。
- 一次資料: [立川市高齢者福祉介護計画改定事前調査報告書](https://www.city.tachikawa.lg.jp/_res/projects/default_project/_page_/001/006/659/keikaku_houkoku_gaiyou.pdf) p.87（PDF 91ページ目）、第3章・在宅介護実態調査・問41。
- 値: 2022年11月15日〜12月13日調査。「介護支援専門員（ケアマネジャー）」55.0%、回答母数 n=331。複数回答の相談先から1項目だけを採用し、他の相談先と合算しない。
- 対象: 在宅の要介護・要支援認定者を抽出した調査における主な介護者についての回答。市内の全介護者の割合ではない。
- 比較: 報告書は2019年度値も併記するが、2019年度調査とは対象者の抽出方法が異なると明記している（同報告書 p.2）。本実装は2022年の一点のみを載せ、増減・指数化をしない。
- 解釈: 「専門職を相談先として挙げた」ことの観測値。相談を必要とした全員への到達率、相談の効果、介護状況の改善率ではない。
- 地域・状態: `geography: tachikawa`、`referenceOnly: false`、`connectionState: connected`。練馬区に同じ値を置かない。
- 更新: 自治体の次回調査で対象・設問・抽出方法が一致することを監査してから追加する。今回の値は原典PDFを再配布せず、必要な加工済み値だけを設定に保持する。

## 共通機能との差分

| 観点 | 確認結果 |
|---|---|
| 出来事レイヤー | 3つの公開ストーリーにカタログあり。今回の単時点調査値は年次グラフでないため重ねない。 |
| Story primitive / 表示制御 | 既存 `SupportConnectionSection` と詳細・振り返りを再利用。値は立川市の source config から processed に入り、care renderer が表示する。 |
| DataGap / 参考値 / 地域 | 練馬区には未確認の調査値を追加しない。都参考の職員・賃金と市内の相談回答を混在させない。 |
| 出典・定義・年度 | 詳細で原典、設問、母数、注意を示す。共通カードには観測時点を表示する。 |
| レスポンシブ / アクセシビリティ | 既存の順序付きリストと詳細表を使用。時点はテキストとして表示し、色に依存しない。 |

大幅な Act 再構成や設計原則の変更は不要。レビュー論点は、相談接点の値を障壁の前に置く現在の読み順が自然かどうか。
