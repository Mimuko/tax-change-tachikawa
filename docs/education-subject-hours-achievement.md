# 立川市×教育｜教科別授業時数と学力指標の採用判断

調査日: 2026-09-27 / 対象 Issue: MY-237

## 結論

**現時点ではストーリーと指標への追加を見送る。** 公開一次資料で立川市の教科別年間授業**実績**を市立学校全体の系列として確認できなかった。確認できた立川市の教育課程表は2022年度開始の「立川市民科」特例校申請に含まれる**計画時数**であり、国語・算数は国の標準時数と同じ。中学校の国語・数学の市独自計画時数は同資料にはない。国の標準時数を立川市の実施状況として表示することもできない。

全国学力・学習状況調査の立川市値は公表されている。ただし対象は小学6年・中学3年で調査は4月実施。同年度の年間時数は調査時点ではほとんど実施前であり、「その時間で得た学力」のような並置は誤解を生む。前年度の時数で照合するにも、同一コホート・学校種・教科に対応する市全体の実績資料がない。したがって新しい系列、DataGap、UIは作らない。既存の教育・介護ページには変更を加えない。

## 一次資料の照合

2023年度の市値は小6国語65%・算数64%、中3国語71%・数学54%。2024年度との差を学力の増減として表示しない。文科省は、調査問題の内容・難易度が年度で異なるため、過年度の平均正答率を単純比較することは適当でないと[調査結果の取扱いに関する報告書](https://www.mext.go.jp/content/20250606-mxt_chousa02-000042646-02.pdf)で明記している。市の公表値を独自に補正・推計しない。

## ストーリーに追加しない理由

1. 学力は4月の特定学年のテスト、時数はその年度全体の教科・学年別計画値で、観測時点と実施状態が一致しない。
2. 国の標準時数は立川市の授業への投入量や実施量を表さない。市の申請書にある国語・算数の数字も標準と同じで、学力との関係を立川市の変化として説明できない。
3. 学力の平均正答率の年度間差は学力の経年変化として扱えない。既存ストーリーの時系列グラフに加えるのは不適切。
4. 時数が未取得というだけで、学力単年値をDataGapの数値的な代理にしない。サイトの第一階層で「学ぶ時間と学力」を並べる目的を満たせない。

## 代替案と再開条件

- 直近の市公表学力調査の4教科を**単年度スナップショット**として別の編集目的で扱うことは可能。市値・全国公立値、対象学年、調査日、年度間比較不可を同じ画面に明示する。今回の「授業時数との関係」には接続しない。
- 文科省の標準授業時数を制度説明として扱う場合、地理範囲を「全国共通」、状態を「標準・計画」と明示し、立川市値や実施済み時数のグラフに置かない。
- 再開するには、市立小中の**実施済み**教科別時数が、年度・学校・学年・教科・集計方法付きで取得でき、調査対象コホートの**調査前**の期間と対応付けられることが必要。年度比較をする場合は学力指標側にも比較可能性の根拠が必要。これらを満たす一次資料を確認してから、`config/topics/education.json` に定義を置き、storyは順序・コピー・可視化のみを担う。

## 検証範囲

この判断は上記の公開一次資料と現行の `config/topics/education.json`、`config/stories/tachikawa-education.json`、`src/stories/education-story.tsx` の照合に基づく。「市全体の実績表が存在しない」という網羅的な不在証明ではない。非公開の教育委員会集計や各校の原簿は対象外。
