# MY-239 PR #15 / #16 統合判断

確認日: 2026-09-27。対象: [PR #15](https://github.com/Mimuko/tax-change-tachikawa/pull/15) と [PR #16](https://github.com/Mimuko/tax-change-tachikawa/pull/16)。自治体とテーマは1組につき1つの公開ルートとする。

| 論点 | #15 `childcare` | #16 `childrearing` | 採用 |
|---|---|---|---|
| テーマ境界・URL | 保育園の定員・利用・職員と子育て相談。`/tachikawa/childcare/` | 妊娠届出、保育園児、学童、相談。`/tachikawa/childrearing/` | **「保育と子育て相談」** を `/tachikawa/childcare/` で1件公開 |
| 主系列 | 同じ[立川市の保育園別 CSV](https://www.city.tachikawa.lg.jp/shisei/tokei/1007009/1007020.html)の「全園」行から定員・実施児童・職員を取る。2019–2023年 | 妊娠届出と保育園児を opening で重ねる。前者は年度累計、後者は時点値 | #15。#16 の opening は同一グラフに異なる期間種別を載せ、既存設計と #16 自身の監査方針に反する |
| 重複する値 | 定員・職員・子育て相談 | 同じ3系列を別名で保持 | 2019–2023年の3系列は全件一致。生成経路と公開表示を重複させない |
| 期間定義 | 保育園別 CSV の基準日が原表上明記されない点を保持 | 同じ保育園別 CSV を「各年4月1日現在」、学童登録を「年度累計」と記す | 未確認の基準日・期間種別は採用しない。学童・妊娠届出は別途監査してから拡張を判断 |
| 原典再現性 | CC BY 4.0 の原本2本を同梱、SHA と取得日を指標別に記録。`data:build` に接続 | 5本を生成時に live fetch、原本は同梱しない | #15 のオフライン再生成経路 |
| 支援への接続 | 相談件数は延べ件数と注記 | 支援を必要とする家庭への到達率は測定不能と DataGap に記録 | **#16 の DataGap の趣旨のみ移植**。同じ相談系列を別セクションで再掲しない |
| イベント | テーマ固有の確証がないため登録なし | 感染症・無償化をグラフイベントとして表示 | 統合時は移植せず。2026-09-27 の再確認で、無償化（2019年10月開始）と保育所向けコロナ対応を一次情報で確かめ直して `config/events/tachikawa-childcare.json` に登録。#16 の出典 URL はいずれも 404、「段階的」の記述は不正確なため使わない。保育園の基準日が不明なため、2019年の値が無償化の前後どちらかは断定しない |

## 統合後の指標と導線

1. 保育園の定員と保育の実施児童数を同じ原表・同じ年次値で比較する。
2. 同じ原表の職員数を別 Act で示す。
3. 子ども家庭支援センターの年度内延べ相談件数を別 Act で示す。
4. 待機児童の比較系列と支援到達率は DataGap とし、定員差・相談件数から推計しない。

妊娠届出と学童は、子育て全般へテーマを広げる場合の候補として残す。現 PoC へ追加するとテーマ境界と期間の説明が広がるため、今回の公開系列には含めない。
