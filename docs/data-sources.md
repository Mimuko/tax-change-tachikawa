## MVP分類

- 必須: 被保険者、認定者、第1号認定率、介護保険給付、サービス別給付、介護保険料基準額。
- MVP採用: 受け皿のサービス別提供単位数（2020〜2024）。
- 参考指標: 東京都のサービス別職員数・常勤換算数、東京都の介護職賃金（いずれも2020〜2024）。
- 可能なら: 計画対実績。
- MVP外: 定義の揃わない系列の結合、推計による市値、全国・自治体比較、将来予測。

保険料収入は取得・財政詳細用には保持するが、「市民負担」の代表指標から除外する。

## 5年比較監査

- 立川市は対象期間中に市町村合併がなく、地域コード132021を継続使用する。
- 立川市統計年報4系列は2012〜2023年度が連続し、現行CSV上に欠損年はない。
- 認定者総数には各年とも第2号被保険者の内数が併記される。第1号認定率は内数を除いて算出する。
- サービス別給付では制度上のサービス新設・廃止があり、「-」を0に変換しない。各サービスの存在期間内だけ比較する。
- 介護サービス情報公表ODは2020年12月末、2021年、2022年、2023年以降のスナップショットを確認できる。年2回ある年は12月末へ固定する。
- 介護療養型医療施設から介護医療院への移行など、制度分類を跨いだ定員・事業所数を同一系列に連結しない。
- 介護保険料基準額は毎年改定値ではなく第8期（2021〜2023年度）・第9期（2024〜2026年度）の制度値である。
- 賃金は2020年の職種分類改定を跨がず、2020年以降で職種・雇用形態・企業規模を固定する。

## raw の保存方針

再配布許諾が明示された原典（例: 立川市 OD の CC BY 4.0）は `data/raw/**` にバイト列をそのまま保持する（`.gitattributes` で `-text`）。改行コードの正規化は行わない。processed の `provenance.sha256` はこのリポジトリ内 raw の実バイトに対する SHA-256 であり、照合は `npm run data:check` で行う。

**再配布許諾が確認できない原典**（例: 練馬区統計書 Excel）は Git に置かない。公開リポジトリでは次だけを管理する。

| 管理するもの | 例 |
|---|---|
| 取得手順・原典 URL・サイトポリシー | `data/raw/<municipality>/.../README.md`, `config/data-sources/...` |
| 期待 SHA-256 | `expectedSha256` / curated `source.sha256` |
| 必要最小限の加工済み系列 | `data/curated/...`（公開に使う数値のみ） |

ローカルで原典を置いた場合のみ、任意で実バイトと期待 SHA を突合する。CI では原典ファイルなしで `data:build` / `data:check` が通ること。CI ではさらに `data:build` 後に `npm run data:stable` で `generatedAt` 以外のドリフトも拒否する。加えて `npm run data:history-check` で base..HEAD の全コミットに local-only 対象バイナリ（練馬区の XLSX/PDF 等）が追加されていないことを検査し、「追加して後から削除」による公開履歴残留を防ぐ。

この区分は今後、許諾を確認していない自治体・資料でも同じ基準で適用する。

## ライセンス記録

現在raw／processedへ収録している立川市オープンデータ5系列は、掲載ページ上で各作品にCC BY 4.0が明示されている。帰属表示を付けた加工・再配布が可能であり、「出典: 立川市オープンデータ（CC BY 4.0）、加工して作成」を基本表記とする。今後追加するPDF・国・東京都・他自治体データは同じ条件と推定せず、資料ごとにクレジット要否、加工可否、再配布可否を確認してから **raw を Git 管理するか** を決める。再配布許諾が無い／不明な場合は raw をコミットせず、URL・SHA・加工済み curated のみとする（上記「raw の保存方針」）。
