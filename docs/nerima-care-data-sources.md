## 5年比較監査

- 練馬区は対象期間中に区制変更なく、地域コード **131202** を継続使用する（総務省市区町村コード・厚労省 OD CSV とも一致）。
- 統計書 Excel 上、介護需要・給付の主系列は **令和2–6年度の5年** を確認。立川版（2012–2023）より短く、長期指数化は **要追加調査**（旧版統計書の監査）。
- 認定者の基準日が **9月末** のため、立川版ストーリーの opening 3系列（被保険者・認定者・給付）を **同一 scrolly にそのまま載せ替え不可**。認定者は別 Act または基準日注記付きの独立系列とする。
- 給付費は千円単位・区分合算。立川 CSV の「総額（円）」列との **1対1対応は未確認**。実装前に令和4年度等で原典照合が必要。
- 提供単位数は立川版と同一 OD 処理（市区町村コード差し替えのみ）。
- 保険料基準額は第9期 **6,670 円/月**（立川 6,183 円/月）。計画期間値として同一 UI 部品（`premium-standard-section`）を再利用可能。
- 職員・賃金は東京都参考のみ。`resolveSupportAvailability` → Case B（Gap + 都参考 chip）を継承。

## 調査上の注意

- オープンデータ一覧（2026-09-09 時点）に介護需要・給付の **年次 CSV は存在しない**。立川版 `scripts/fetch-data.mjs` はそのまま使えない。
- 「ねりまの福祉」年報 PDF は市民向け実績報告。数値の二次利用前に、統計書 Excel との定義一致を確認する。
- 事業所一覧 OD は単時点。件数を過去と比較してはならない（`docs/data-definition.md` §受け皿 と同趣旨）。
- 地域包括ケア「見える化」資料の認定率・1人あたり給付は **国・都との比較用調整値**。市区町村の FINALE 主系列に流用しない。
